# Lab Automation & CI/CD Pipelines

> **Track:** OpenClaw Real-World Lab Build (Track 3)
> **Course 4 of 5**

Automate cluster configuration, deployments, and testing with Ansible and GitHub Actions.

---

## Modules

### Module 1: Ansible Playbooks for Mac Clusters

**Learning Objectives:**
- Write playbooks for cluster bootstrap
- Use Ansible Vault for secrets
- Run ad-hoc commands across all nodes

### Module 2: GitHub Actions for Lab Deployments

**Learning Objectives:**
- Trigger deployments on git push
- Self-host GitHub Actions runners on Mac Minis
- Implement manual approval gates for production

### Module 3: Automated Testing Environments

**Learning Objectives:**
- Spin up isolated test environments per PR
- Run integration tests against live lab nodes
- Tear down environments on test completion

### Module 4: Rolling Updates with Zero Downtime

**Learning Objectives:**
- Implement blue-green deployments on the cluster
- Roll back deployments with a single command
- Validate health checks before traffic cutover
